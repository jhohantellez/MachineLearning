Multinomial Naive Bayes

What the Model Is

Multinomial Naive Bayes is a probabilistic classification algorithm based on Bayes' Theorem. It is mainly used for discrete data such as word counts in text classification problems. The model assumes that features are conditionally independent given the class.

How It Works (General Terms)

The model calculates the probability that a document belongs to a specific class by combining:

  • The prior probability of the class
  • The likelihood of the words appearing in that class

It multiplies the probabilities of each word (based on their frequency) and selects the class with the highest probability.

Mathematical Formula

P(Ck | d) ∝ P(Ck) * ∏ P(xi | Ck)^fi

Where:

  • P(Ck): Prior probability of class Ck
  • xi: Word (feature)
  • fi: Frequency of word xi in the document
  • P(xi | Ck): Probability of word given the class

Likelihood with Laplace smoothing:

P(xi | Ck) = (Nik + α) / (Nk + α * |V|)
  • Nik: Count of word xi in class Ck
  • Nk: Total number of words in class Ck
  • |V|: Vocabulary size
  • α: Smoothing parameter (usually 1)

Main Characteristics

  • Uses frequency of words (bag-of-words model)
  • Assumes independence between features
  • Works with discrete data
  • Applies Laplace smoothing to avoid zero probabilities

Advantages and Limitations

Advantages

  • Simple and fast
  • Efficient with large text datasets
  • Good baseline model for classification

Limitations

  • Strong independence assumption (not always realistic)
  • Ignores word order and context
  • Not ideal for continuous data

Type of Classification Problems

  • Email spam detection
  • Sentiment analysis
  • News categorization
  • Document classification

Real-World Use Example

In email spam filtering, the model analyzes the frequency of words such as "free", "offer", or "win". Based on training data, it calculates probabilities and determines whether a new email is spam or not.
