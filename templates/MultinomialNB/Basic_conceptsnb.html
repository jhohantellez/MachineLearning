Multinomial Naive Bayes

Multinomial Naive Bayes model visualization

What the Model Is

Multinomial Naive Bayes is a probabilistic classification algorithm based on Bayes' Theorem. It is designed for discrete data, especially word counts in text classification tasks.

How It Works

The model estimates the probability that a document belongs to a class by combining:

  • Prior probability of the class
  • Likelihood of each word appearing in that class

It multiplies all probabilities and selects the class with the highest score.

Mathematical Formula

P(Ck | d) ∝ P(Ck) × ∏ P(xi | Ck)^fi

Where:

  • P(Ck): Prior probability
  • xi: Word (feature)
  • fi: Frequency
  • P(xi | Ck): Likelihood

Laplace Smoothing

P(xi | Ck) = (Nik + α) / (Nk + α × |V|)

Main Characteristics

  • Uses word frequency (bag-of-words)
  • Assumes independence between features
  • Works with discrete data
  • Applies Laplace smoothing

Advantages & Limitations

Advantages

  • Fast and simple
  • Efficient with large datasets
  • Excellent for text classification

Limitations

  • Strong independence assumption
  • Ignores word order
  • Not ideal for continuous variables

Applications

  • Spam detection
  • Sentiment analysis
  • Document classification

Real-World Example

Gmail Spam Filter

Emails are analyzed based on word frequencies. Words like "free" or "winner" increase spam probability, while words like "meeting" or "invoice" decrease it.
