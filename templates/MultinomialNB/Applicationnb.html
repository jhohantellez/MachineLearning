Assigned Classification Model: SMS Spam Detection

Problem Description

This project addresses the automated classification of Short Message Service (SMS) to identify unwanted or malicious content. By utilizing the Multinomial Naive Bayes algorithm, the system analyzes word frequencies to determine the probability of a message being legitimate (Ham) or junk mail (Spam).

Dataset Explanation & Variables

The SMS Spam Collection Dataset (UCI Machine Learning) is used. The data was preprocessed using:

  • Variables Used: Text content of the SMS (Independent variable) and Binary label 0/1 (Dependent variable).
  • Data Preparation: Count Vectorization (Bag of Words) to convert text into numerical tensors based on word frequency.
