Linear Regression

What is Linear Regression?

Linear regression is a Machine Learning model used to predict numerical values based on one or more input variables. It establishes a linear relationship between the variables.

Mathematical Model

y = mx + b
  • y: value to predict
  • x: input variable
  • m: slope (rate of change)
  • b: intercept (initial value)

Example

Linear regression can be used to predict a student's exam score based on study hours, or estimate the price of a house based on its size.

Types of Linear Regression

  • Simple Linear Regression: uses one variable
  • Multiple Linear Regression: uses multiple variables

Model Error

The model tries to minimize the difference between actual values and predicted values. One common metric used is the Mean Squared Error (MSE).

Applications

  • Price prediction
  • Trend analysis
  • Finance
  • Data science
