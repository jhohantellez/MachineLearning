Statistical Modeling

Linear Regression

Fundamentals of supervised learning used to predict continuous numerical values by modeling the relationship between dependent and independent variables.

Mathematical Framework

The Linear Model

Linear regression establishes a relationship between a dependent variable (y) and one or more independent variables (x) using a straight line.

y = mx + b

  • y: Predicted value (Target)
  • x: Input variable (Feature)
  • m: Slope (Rate of change/Weight)
  • b: Intercept (Initial value/Bias)
Model Logic

Simple vs Multiple

Simple: Uses only one input variable to predict the outcome.

Multiple: Uses two or more variables (x1, x2, x3...) for more complex predictions.

The Goal: Optimization

The model finds the "best fit" line by minimizing the Mean Squared Error (MSE). It calculates the average of the squared differences between actual and predicted values.

Real World

Core Applications

Forecasting

Predicting market trends, house prices, or weather temperatures based on historical data.

Analytics

Estimating the impact of marketing spend on total sales or user growth.

Science

Modeling biological growth or chemical reactions based on controlled variables.
