Introduction

What is Logistic Regression?

Logistic Regression is a supervised learning algorithm designed for classification problems. Instead of predicting a number, it predicts the probability that an input belongs to a class.

These probabilities are then converted into decisions such as approved/rejected or yes/no.

The key difference from linear regression is that outputs are constrained between 0 and 1 using a nonlinear transformation.

Regression vs Classification

Regression: predicts continuous values

Classification: predicts categories

Binary Classification

Used when there are only two possible outcomes: 0 or 1.

Target Variable

The output the model predicts. Example: Loan Approved (1 or 0).

Features

Input variables such as age, income, or credit score that influence predictions.

Sigmoid Function

Converts linear output into a probability between 0 and 1.

Decision Boundary

The threshold where the model switches from one class to another.

Threshold

Usually 0.5 — determines final classification.

Log Loss

Measures how wrong predictions are, penalizing confident errors.

Real Application

Used in loan approval, fraud detection, and medical diagnosis.

Interpretation

How to read the model

Logistic regression outputs probabilities. A high probability (e.g. 0.9) means strong confidence in the positive class.

Metrics like accuracy, precision, recall, and ROC-AUC are used to evaluate how well the model performs.
