Logistic Regression

What is Logistic Regression?

Logistic regression is a supervised Machine Learning algorithm used for classification tasks. Unlike linear regression, which predicts continuous values, logistic regression predicts probabilities that an input belongs to a specific class. These probabilities are then converted into discrete outcomes such as 0 or 1.

It is widely used in real-world applications where decisions must be made between two or more categories, such as loan approval, disease detection, or fraud identification.

Difference Between Regression and Classification

  • Regression: predicts continuous numerical values (e.g., salary, house price).
  • Classification: predicts categories or class labels (e.g., approved/rejected).

Logistic regression is called "regression" because it models probabilities using a regression-like equation, but its final output is used for classification.

Binary Classification

Binary classification refers to problems where there are only two possible outcomes. Logistic regression is most commonly used in this scenario, where:

  • 0 → Negative class (e.g., loan not approved)
  • 1 → Positive class (e.g., loan approved)

Target Variable / Class Label

The target variable is the output that the model is trying to predict. In classification problems, this is called the class label. It represents the final decision or category.

In this project:
Loan_Approved = 1 → Approved
Loan_Approved = 0 → Not Approved

Features / Predictors

Features are the input variables used by the model to make predictions. These variables contain the information that helps the model learn patterns in the data.

  • Age
  • Income
  • Credit Score
  • Loan Amount
  • Loan Term
  • Employment Status

Probability Estimation

Logistic regression uses the sigmoid function to transform any real-valued number into a value between 0 and 1, which represents a probability.

p = 1 / (1 + e-(mx + b))

The output probability indicates how likely it is that a given input belongs to the positive class.

Decision Boundary

The decision boundary is the point where the model separates different classes. It defines the limit between predicting one class or another.

In logistic regression, this boundary is typically based on a probability threshold.

Classification Threshold

The classification threshold is used to convert predicted probabilities into class labels.

  • If probability ≥ 0.5 → Class = 1
  • If probability < 0.5 → Class = 0

This threshold can be adjusted depending on the problem. For example, in financial applications, a higher threshold may be used to reduce risk.
