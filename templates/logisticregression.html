Understanding Logistic Regression

Logistic Regression is a classification algorithm used to predict the probability that a data point belongs to a certain class.

Instead of predicting continuous values, it outputs probabilities using the sigmoid function.

Key idea: The model transforms a linear combination of inputs into a probability between 0 and 1, then applies a threshold to classify.

Sigmoid Function

Maps any real value into a probability between 0 and 1 using: σ(x) = 1 / (1 + e⁻ˣ)

Probability Output

The model predicts the likelihood of belonging to class 1 instead of a raw value.

Decision Threshold

A cutoff (usually 0.5) is used to convert probabilities into final class labels.

Log Loss

Measures classification error. Penalizes confident wrong predictions heavily.

Binary Classification

Used for problems with two outcomes such as yes/no, spam/not spam.

Model Interpretation

Coefficients indicate how each feature influences the probability of the outcome.
