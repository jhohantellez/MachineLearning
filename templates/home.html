Foundation

What is Machine Learning?

Unlike traditional imperative programming where we define explicit if/else logic, Machine Learning uses statistical algorithms to autonomously detect patterns within large datasets.

The objective is to construct a mathematical model capable of generalizing behaviors and making high-precision predictions when exposed to previously unseen data.

Engineer's Note: ML is not "magic"; it is applied multivariable calculus and linear algebra. Success depends on data quality and hyperparameter tuning.

Supervised Learning

Training models with labeled data (Input/Output pairs) for Regression and Classification tasks.

Unsupervised Learning

Discovering hidden structures and natural groupings (Clustering) in data without prior labeling.

Core Concepts

Train vs Test

Splitting data to prevent Overfitting and ensure the model can generalize to real-world scenarios.

Features & Labels

Features are independent variables (inputs); Labels are the target values the model aims to predict.

Loss Function

A mathematical algorithm that quantifies the "distance" between the prediction and the actual value during training.

Evaluation Metrics

Using Accuracy, Precision, and Recall to validate the technical performance and reliability of the model.
