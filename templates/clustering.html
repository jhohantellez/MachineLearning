Customer Segmentation

Grouping unlabeled data into meaningful clusters using the K-Means algorithm. Discover hidden patterns and natural groupings within complex datasets.

Project Overview

Pattern Discovery Through Clustering

This implementation demonstrates how K-Means Clustering partitions data into K distinct groups by minimizing the distance between each point and its assigned centroid.

Methodology: The algorithm iteratively assigns data points to the nearest centroid and recalculates centroid positions until convergence, optimizing intra-cluster cohesion.

Feature Set

Numerical attributes used to measure similarity and group data points into clusters.

Model Type

K-Means Clustering (Scikit-Learn implementation) with configurable number of clusters.

Objective

Minimizing intra-cluster variance (inertia) to find the most compact and separated groups.
