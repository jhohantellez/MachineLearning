Unsupervised Learning

K-Means Concepts

Understanding the theory and mathematics behind the K-Means clustering algorithm.

Core Idea

What is K-Means?

K-Means is an unsupervised learning algorithm that groups data into K clusters. Unlike supervised learning, it works without labeled data — it finds structure on its own.

Key insight: Each cluster is represented by its centroid — the average position of all points belonging to that group.

Algorithm Steps

1. Choose K (number of clusters).

2. Randomly initialize K centroids.

3. Assign each point to the nearest centroid.

4. Recalculate centroids as the mean of assigned points.

5. Repeat steps 3–4 until convergence.

Distance Metric

Uses Euclidean distance to measure how close a point is to each centroid. The point is assigned to the cluster with the smallest distance.

Inertia

The sum of squared distances from each point to its centroid. A lower inertia means more compact and well-separated clusters.

Elbow Method

A technique to choose the optimal K by plotting inertia vs. number of clusters and finding the "elbow" where improvement slows down.

Centroids

The center of each cluster. After convergence, each centroid represents the "average profile" of all data points in its group.

Convergence

The algorithm stops when centroids no longer move significantly between iterations, meaning the clusters have stabilized.

Limitations

K-Means assumes spherical clusters and requires K to be defined upfront. It is sensitive to outliers and initial centroid placement.
