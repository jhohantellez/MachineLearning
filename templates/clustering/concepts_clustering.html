Unsupervised Learning

K-Means Concepts

A complete guide to the theory behind K-Means Clustering — from unsupervised learning fundamentals to real-world applications.

01
Foundation

What is Unsupervised Learning?

Unsupervised learning is a branch of machine learning where the model is trained on data without labels. There is no "correct answer" to guide the algorithm — it must find structure and patterns on its own.

Unlike supervised learning (where you provide input-output pairs), unsupervised learning explores the data freely, discovering hidden relationships and natural groupings.

Supervised vs Unsupervised

Supervised: Learns from labeled data (e.g., spam vs. not spam).

Unsupervised: Finds structure in unlabeled data with no predefined categories.

02
Core Concept

What is Clustering?

Clustering is the task of grouping a set of objects so that items in the same group (called a cluster) are more similar to each other than to those in other groups.

Think of it like sorting a pile of mixed fruits by color and size — without anyone telling you the categories in advance.

Intra-cluster

Points inside a cluster should be as similar as possible.

Inter-cluster

Points across clusters should be as different as possible.

03
The Algorithm

What is K-Means?

K-Means is the most widely used clustering algorithm. It partitions N data points into K clusters, where each point belongs to the cluster with the nearest centroid.

The "K" refers to the number of clusters you choose before running the algorithm. Selecting the right K is a critical step — often done using the Elbow Method, which plots inertia vs. number of clusters to find the optimal value.

04
Key Element

Centroids

A centroid is the geometric center of a cluster. It is calculated as the mean of all data points assigned to that cluster.

The centroid does not have to be an actual data point — it is simply the average coordinate in the feature space.

μk = (1 / |Ck|) × Σ xi

Centroid Update Rule

After each assignment step, the centroid is recalculated as the mean position of all points in its cluster. This pulls the center toward the true heart of the group.

05
Measurement

Distance Metrics — Euclidean Distance

K-Means uses Euclidean distance to measure how close a data point is to each centroid. The point is assigned to the cluster whose centroid is nearest.

d(x, μ) = √ Σ (xi − μi)²

Where x is the data point and μ is the centroid.

Small distance

The point is very similar to its centroid — a good cluster fit.

Large distance

The point is far from its centroid — may belong to another cluster.

06
How It Works

The Iterative Process

K-Means runs in repeated cycles until the clusters stabilize. Each cycle has two steps: assignment and update.

1

Initialize: Randomly place K centroids in the feature space.

2

Assign: Calculate the distance from each data point to every centroid. Assign each point to its nearest centroid.

3

Update: Recalculate each centroid as the mean of all points currently assigned to it.

4

Repeat: Go back to step 2. Continue until centroids stop moving or a maximum number of iterations is reached.

07
Optimization

Variance and Convergence

K-Means minimizes inertia — the sum of squared distances between each point and its centroid. Lower inertia means tighter, more compact clusters.

Inertia = Σ Σ ‖xi − μk‖²

Convergence occurs when the centroids no longer change position between iterations — meaning the algorithm has found a stable solution.

Local Minima

K-Means is not guaranteed to find the global optimum. The result depends on initial centroid placement — that's why K-Means++ was developed to improve initialization and avoid poor starting points.
