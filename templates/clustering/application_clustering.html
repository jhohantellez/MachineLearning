Unsupervised Learning

K-Means Application

Customer segmentation using clustering techniques to identify patterns in financial behavior.

Context

Dataset Context

This dataset represents credit card customers and their financial behavior. The goal is to identify different types of clients based on their credit usage and transaction activity using unsupervised learning.

Dataset

Dataset Explanation

Number of records: 10,000+

This dataset contains customer financial information used to analyze behavior patterns.

Features

Credit_Limit

Total_Trans_Amt

Data Preprocessing

Missing values were removed and features were standardized using StandardScaler to ensure fair distance calculations.

Model

Model Training

The K-Means algorithm was applied using Scikit-learn. The model groups customers into K clusters based on similarity using Euclidean distance.
