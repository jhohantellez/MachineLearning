Manual K-Means Project

K-Means Results

Analysis of a manual clustering simulation developed with 100 records and 3 iterations using Euclidean distance logic.

01 Dataset

Dataset Explanation

This manual K-Means simulation was developed using a dataset composed of 100 records, each represented by two numerical variables: X and Y.

These variables can represent measurable attributes such as age and income, production and cost, or any pair of continuous values.

03 Calculation

Distance Calculations

To determine cluster membership, the Euclidean Distance metric was applied between every data point and each centroid.

Formula: d = √((x₂ - x₁)² + (y₂ - y₁)²)

Interpretation of Results
